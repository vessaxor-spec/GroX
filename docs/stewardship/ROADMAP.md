# GroX Roadmap

## Current position

The independence baseline is now being converted into a runnable GroX-native Vessel in the local sandbox.

## Current vector

**Operational bootstrap:** Commander Seat → GorXu → Mission Control → Standing Crew → bounded tools → evidence → independent verification → durable state.

## Next candidate vectors

- richer Crew dossiers and organizational memory
- durable resumable workflow engine
- secure shell/browser Tool Gateway
- model-provider adapters for GorXu and Crew cognition
- advanced Crew routing, Divisions, recruitment, and evolution
- evaluation, telemetry, and evidence provenance
- deployment and host isolation

## Locked persistence foundation

The three-plane persistence architecture is now foundational infrastructure for the Apex run:

- Project-bound GorXu cognitive continuity;
- GitHub-bound Vessel source;
- private, integrity-checked operational-state snapshots;
- replaceable sandbox/host compute;
- gated reconstitution before Mission resume.

This foundation is not a competing roadmap vector. It exists so every later Apex stage can survive model, session, and host turnover.
