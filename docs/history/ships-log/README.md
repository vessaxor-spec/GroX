# Ship's Log

The Ship's Log records major milestones in the life of the Vessel.

Entries are sequential and historical. They do not override architecture, specifications, code, tests, or Commander directives.

Earlier entries 0001–0016 were created during the prior sandbox build and are not yet present in this repository. Their numbering is reserved pending recovery so historical continuity is not rewritten.

New major milestones should use the next sequential entry number and record only what is supported by current evidence.
